Sources of a simple http web server that can return any TDataItem structure and data, execute queries and create TeeChart images from your data.

BIWeb server enables TDataItem objects to be linked transparently between local and remote sites.

The server can be a standalone Windows executable, an Apache module, IIS plugin, Linux etc.
These sources can be used as an example to create your own server.

[See live examples](https://rawgit.com/Steema/BI/master/demos/online/remote_web/index.htm) of BIWeb running at steema.cat 


## Please find documentation about BIWeb web server at TeeBI wiki:

[https://github.com/Steema/TeeBI/wiki/biweb](https://github.com/Steema/TeeBI/wiki/biweb)

Data can optionally travel encripted or compressed.
